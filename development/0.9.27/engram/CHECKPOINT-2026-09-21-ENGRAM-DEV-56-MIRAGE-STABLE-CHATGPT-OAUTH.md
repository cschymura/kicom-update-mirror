## Actual platform documentation and former blocker

Current OpenAI plugin OAuth docs https://developers.openai.com/plugins/build/auth confirm the documented stable ChatGPT callback `https://chatgpt.com/connector_platform_oauth_redirect` and stable ChatGPT client ID `https://chatgpt.com/oauth/client.json` when the authorization server supports RFC 9207, advertises `authorization_response_iss_parameter_supported=true` and provides identical `iss` in every callback authorization success/error response. Without such issuer support, ChatGPT uses a callback-ID-specific redirect that must be retrieved from its plugin connection UI. Stable client ID alone is not a substitute for verified client authentication or creating/connecting a real plugin.
